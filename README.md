# China Web Agent Bench（中文网页 Agent 评测集）

量化 AI agent 在**中文互联网平台**上完成真实任务的能力。

现状：browser-use（24k star）等 web agent 项目的评测几乎全是英文站点。
中文平台特有的登录墙、滑块、iframe、动态渲染、反自动化检测，没有公开基准。

## 首轮结果（v0.1）

10 个任务 × 3 轮 = 30 次运行，成功率 **37%**，平均耗时 37.6s。

登录墙是最大阻碍（占失败原因 56%）。完整数据见 [docs/report-v0.1.md](docs/report-v0.1.md)。

| 稳定通过 | 部分通过 | 完全失败 |
|---|---|---|
| 12306(3/3)、知乎(3/3) | 闲鱼(1/3)、携程(2/3)、快递100(2/3) | PDD(0/3)、1688(0/3)、抖音(0/3)、淘宝(0/3)、小红书(0/3) |

## 相关项目

**[session-keeper](https://github.com/brianwang/session-keeper)** — 多平台浏览器登录态管理。
本评测里 56% 的失败来自登录墙，那个项目专门解决这个问题：持久化 profile、
结构化状态检测、headed 重登引导。两者配合使用效果最好。

## 设计原则

1. **只读任务**：查、看、搜。不发布、不下单、不发消息、不注册。
2. **真实平台**：全部是真实在运营的中文网站。
3. **可复现**：每个任务给出步骤、成功判据、登录要求。
4. **记录障碍**：不只记成功/失败，还记「被什么挡住」（登录墙/滑块/验证码/JS 渲染）。

## 评分维度

每个任务记录：

- `success`: 是否完成（bool）
- `duration_ms`: 耗时
- `blocked_by`: 被什么挡住（`none` / `login` / `captcha` / `slider` / `anti-bot` / `timeout` / `parse-fail`）
- `extracted`: agent 是否正确提取目标数据

汇总指标：

```
成功率 = 成功任务数 / 总任务数
平均耗时
各平台阻塞类型分布
```

## 用法（规划）

```bash
# 跑全部任务（无头）
python runner/run.py

# 跑单个任务
python runner/run.py --task T01

# 输出报告
python runner/run.py --report results/latest.md
```

## 目录

```
tasks/        每个任务一个 YAML（步骤、判据、登录要求）
runner/       执行器（Playwright）
results/      历次运行结果
docs/         平台特性笔记（登录机制、反爬策略）
```

## 免责声明

本评测集仅用于学术研究和技术评估，所有任务为只读操作，不涉及数据抓取、批量请求或绕过付费墙。
