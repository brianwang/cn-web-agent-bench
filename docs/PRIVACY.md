# 隐私与数据说明

## 数据来源

本评测集的所有任务都在**公开可访问**的网页上进行，与匿名访客看到的内容一致。
不涉及：

- 登录后的私密数据抓取（`requires_login: true` 的任务仅用于评估登录墙的存在，不采集任何账号内容）
- 批量请求、爬虫、绕过付费墙
- 任何个人信息的收集或转发

## 仓库内不含

- 真实账号、密码、cookie、token
- 真实订单号、快递单号（测试用 `SF1234567890` 等假数据）
- 真实店铺名、用户名
- 运行结果中的真实数据（`results/` 已在 `.gitignore` 中排除）

## 运行时的数据

`runner/run.py` 运行时会把页面文本发送给配置的 LLM 用于决策。
如果在意，可自行替换 `CLAUDE_BIN` 为本地模型。

运行产生的 `results/*.json` 可能包含当次页面的部分文本，**请勿提交到公开仓库**。
`.gitignore` 已默认排除。

## 使用限制

- 低频运行（建议单任务间隔 ≥ 30 分钟），避免对平台造成压力
- 遵守各平台的用户协议与服务条款
- 本项目仅用于技术研究与评测，不构成对任何平台的使用授权

## 联系

如平台方认为某个任务不合适，提 issue 即可，会移除。
